
# Customer Churn Prediction System

## About
A machine learning web application that analyzes telecom customer data and predicts whether a customer is likely to leave a service.

## Features
- Customer dataset overview
- Customer churn visualization
- Random Forest classification model
- Model accuracy and performance report
- Interactive customer churn prediction form

## Technologies Used
- Python
- Pandas
- Scikit-learn
- Streamlit
- Matplotlib

## Dataset
Telco Customer Churn dataset.

## How to Run

1. Install Python.
2. Install the required libraries:

   ```bash
   pip install pandas numpy scikit-learn streamlit matplotlib seaborn
   ```

3. Keep `customer_churn.csv` in the same folder as `app.py`.
4. Run the application:

   ```bash
   streamlit run app.py
   ```
